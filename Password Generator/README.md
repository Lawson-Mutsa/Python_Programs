# 🔐 Password Generator

A Python program to generate **secure passwords**. Users can either **customize their password** or let the program **auto-generate** one for them.

---

## **Features**

- Generate passwords with a mix of:
  - Lowercase letters
  - Uppercase letters
  - Numbers
  - Special symbols
- Choose to **customize your password** or **auto-generate** one.
- Simple and interactive console interface.

---

## **Usage**

1. Clone the repository or download `password_generator.py`.
2. Run the program:

```bash
python password_generator.py
